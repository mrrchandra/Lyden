## Goal (Prompt.txt §6.3 milestone 11)

> **CLS-style editable memory actually learned by the model: read/write/edit
> at the buffer; success = deterministic fact-fix recall + session val gain.**
>
> Precise target: after M11, `generate_with_clm()` (already implemented +
> unit-tested: `src/lyden/memory/loop.py`) should behave *intelligently* —
> the 100M model emits valid `<|edit|>…<|/edit|>` commands because it was
> trained on sessions where they are the right thing to do.

Window stays **1,024** (per user decision; long-context gets its own ladder,
see `ROADMAP.md`).

## Design

### 1. CLM session data (the new ingredient)

Synthetic "expert transcripts" built at data-prep time from TinyStories,
mixing the REAL buffer semantics (`ContextBuffer.read/write/replace/delete`
+ `summarizer`):

- Session pages: story/facts presented → model writes summary lines into
  an in-session buffer (`<|context|>` render `<|/context|>` block) →
  a fact is contradicted → the model (template-driven) emits
  `REPLACE line n …` inside `<|edit|>…<|/edit|>` → later page asks about the
  corrected fact; the answer uses the CORRECTED value. Such a transcript is
  "ideal behavior by construction" ( imitation teaching, v1; on-policy RL is
  out of scope).
- Every session's edit markers are real (buffer lines are 1-based, matching
  `commands.py` grammar) and every page tokenizes with the standard
  specials (no new tokens needed).

Mix per step: **70% raw TinyStories / 30% CLM sessions** (packing keeps the
trainer untouched: the sessions are just longer documents).

### 2. MoE balance fix (bundled, before the run)

M10 recorded: gate sat at ≤0.97, effective experts ≈2. ROOT CAUSE FOUND while
implementing (not gamma tuning as first assumed): **the trainer never called
`update_bias()` — the loss-free balancer had no call site at all in M10**, so
the bias stayed zero across the entire run; stats were collected but never
used for control. Fix set (implemented + unit-tested):

- **Call site per optimizer step** in `Trainer.step()` (loads averaged over
  micro-batches and, under DDP, across ranks so bias stays world-consistent);
- **Reset bias → 0 at resume** when `training.reset_moe_bias=true`
  (fresh balancing epoch);
- **gamma ramp** `MoEConfig.bias_gamma_ramp=(0.004, 0.001, 400)` (early
  escape pressure, then DeepSeek-style 1e-3);
- **router z-norm** `MoEConfig.router_znorm=true` (per-token standardized
  scores; affine ⇒ selection unchanged, bounded scale for bias deltas).

Success bar (all four routed layers, end of run): `load_top ≤ 0.5`,
`entropy ≥ 1.95`, zero `load_top ≥ 0.95` gate spikes.

### 3. Training run

Same proven 2×T4 DDP commit-run flow (v3 of the Kaggle notebook; load
`ckpt_0007600.pt` from own-output + the four cached wheels:

- steps: **2,000** (≈65.5M new tokens, loss-free M10 style) at
  trunk_lr 4e-5-ish ceiling (the ckpt's scheduler logic continues);
- fp16 lives as-is (world-shared scale restore, 64 initially);
- ~1.5–2 h wall, split across standard eval + CLM metric pages.

### 4. Evaluation (the milestone's stop-and-report bar)

1. **Fact-fix recall** (the headline): script `scripts/m11_eval_memory.py`
   — 100 held-out fact-edit sessions; each asks the final fact twice:
   once pre-edit, once post-edit (deterministic T=0 sampling).
   Metric: % answers correct AFTER fix (target ≥ 90% syntax; ≥ 80% values).
2. **Session val-ppl**: held-out CLM-session val pages — expect ppl < 14
   (story-only M10 baseline) and falling after edits appear.
3. **MoE balance** per §2 bar.
4. **Story regression guard**: plain-tinyStories holding on ppl < 15.

## Cost / timeline
- Local dev + tests only (no GPU burn)
- Kaggle run: ~2 h / 2×T4 (quota left ≈ 33 h → fits with margin)

## Risks
- Edit-syntax frequency collapse (model stops using buffer): guarded by the
  30% mix + pre-run sanity probe after 100 steps.
- fp16 under-load loading the MoE fix: world-shared scale path already
  proven.
- Memory loop's re-prefill at every edit is slow in the local demo; not a
  training issue (compile-time behavior only).

## Out of scope (explicit)
- Long-context rung (2K+) — separate experiment per ROADMAP.
- On-policy memory-policy RL (Prompt.txt stretch goal; M13+).
- 2,048+ windows; no model topology changes (same 339 tensors).
