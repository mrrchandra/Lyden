## What M11 was

Continue-train the M10 checkpoint (step 7600) for 2,000 steps (~65.5M tokens, seq 1024) on a mixture of TinyStories + synthetic fact-fix CLM sessions (ratio 2, 26.7% session share), with the MoE balancer fix wired into `Trainer.step` (`update_bias` per step) and router z-norm + gamma ramp 0.004→0.001 @400. Success bar: held-out fact-fix recall ≥ 0.80 (T=0), story ppl ≤ 15, load_top ≤ 0.5 and entropy ≥ 1.95 on all 4 routed layers.

## Bugs found and fixed during M11 (all TDD'd, tests green: 132 passed, ruff+mypy clean)

1. **MCP bridge drops data-source fields** — `kernelDataSourcesSetter`/`datasetDataSourcesSetter` in `save_notebook` are silently ignored → v3/v4/new-notebook launched with empty `/kaggle/input`. Fix: classic `kaggle` CLI push via `kernel-metadata.json` (supports `machine_shape` + `dataset_sources`).
2. **Guard typo** — `cp "$TOKJ".json` produced `tokenizer.json.json` (commit 6f9d2c2).
3. **Cross-phase bound bug** — `--resume` treated `total_steps=2000` as absolute, so `7600 < 2000` → instant exit ("[done] reached step 7600 in 0.0 min"). Fix: cross-phase bound = `entry_step + total_steps` (7600→9600); own-phase auto-resume unchanged (absolute); `--max-steps` = new steps this process. Regression test `tests/test_ddp.py::test_train_py_cross_phase_continue_runs_new_steps` (commit 8f8f349).
4. **World-size compensation** — `--accum-mult` (commit 9b8da74): single-GPU retries multiply grad_accum by `2 // NPROC` to keep effective batch constant.

## Infra lessons (carry forward)

- Kaggle **P100 is retired**; T4×2 is the reliable workhorse.
- Max 2 batch GPU sessions per account — zombie queued sessions hold slots (`kernels delete` to free).
- **Interactive (draft) sessions expose no console logs and no output files** via API until the session ends; batch runs expose everything at completion. For future milestones: always run batch (Save & Run All) so the loop can monitor.
- Kaggle slug follows the notebook *title* on push — keep titles stable to avoid 409 conflicts.
- WSL `/tmp` is wiped between sessions — stage all Kaggle I/O under `/home/madrin`; long uploads must run detached (`powershell Start-Process wsl.exe ...`).
- Wheel build (~64 min: mamba-ssm + flash-attn from source) dominates every run — next: add built wheels to the backup dataset (v2) to skip compilation.
